# 机会评价模板

尚未调查。本文件仅提供格式。

- 方向 ID、轮次、名称和状态
- 问题、客户及付款者
- 适配理由、个人优势及证据
- 收费模式、收入估算口径
- 启动条件、预算、时间
- 硬约束检查、冲突项和待核实约束
- 适用时估算单位贡献、盈亏平衡销量、回款和工时容量
- 首次市场验证时间估算
- 主要风险、事实、推断、假设与未知
- 维持当前收入路径的机会成本、可能改变排名的关键未知
