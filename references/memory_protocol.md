# 本地记忆协议

技能根目录由实际 SKILL.md 定位，memory/README.md 是每次调用入口，记录状态、画像确认、当前方向 ID、下一步、相关路径和待确认冲突。

| 文件 | 职责 |
| --- | --- |
| PROFILE.md | 基本情况、兴趣动机、工作方式、性格行为 |
| SKILLS.md | 学过、掌握、独立交付、证据和局限 |
| EXPERIENCE.md | 项目、成功失败、个人贡献、成果和第三方反馈 |
| RESOURCES.md | 人脉、客户渠道、资金设备、行业知识与其他优势 |
| VALUES_AND_GOALS.md | 收入期限、财富生活目标和价值取舍 |
| CONSTRAINTS.md | 周投入、预算、亏损、责任、地区与合作限制 |
| INTERVIEW_LOG.md | 已问问题、回答摘要、跳过项和下一追问 |
| OPPORTUNITY_LOG.md | 稳定方向 ID、轮次、评分、状态及证据链接 |
| DECISION_LOG.md | 选择、否定、放弃、跳步与状态变化 |
| research/market/ | 市场判断与来源 |
| research/competitors/ | 竞品事实、报价和比较 |
| research/customer_evidence/ | 实际访谈、行为与交易 |
| selected_direction/ | 活动方向分析、验证和执行 |

每条信息记录日期、来源、事实/推断/假设/未知、用户确认状态、核实状态和证据路径。初始化为“尚未调查”。模板仅提供结构。

## 写入顺序

1. 读取当前内容，局部更新相关部分，避免重复抄写。
2. 明确回答标用户提供，画像总结待确认，推断单列。矛盾信息保留双方来源和日期，标待确认冲突，下一轮问一个澄清问题。用户明确更新则记录新旧生效日期。
3. 先写事实及证据，再写决定，最后更新 README。中途失败时回读并补齐，不能报告全部成功。
4. 回读检查链接、当前方向和状态。存在并发修改时重新读最新版本再合并。
5. 重要变化保留必要历史，旧方向保存至 selected_direction/history/<方向ID>/<归档批次>/，批次名唯一，日志索引。兼容读取已有方向目录中的直接归档文件，重复切换时不覆盖旧批次。
6. 缺文件仅补建当前需要部分。用户明确本轮不保存时保持磁盘不变。

README 的恢复摘要只保存当前状态、活动方向/实验 ID、最近决定、待用户回答的问题或下一行动及依据路径。长期原始记录留在对应日志或证据文件。恢复时按路径核对正文，索引与正文冲突时查清最近可追溯变化后修正，关键决定不明时问一个澄清问题。继续使用旧版 README 时按需补充字段，无需重建档案。

再次用于重要决策前核对易变目标、约束和市场证据的日期。根据内容变化速度与决定影响选择是否复核，避免把历史研究结论直接当成当前事实。

## 管理与删除

支持查看画像、历史访谈、所有机会、已放弃方向、历史选择和活动项目，以及修改目标和约束。

用户要求忘记某条信息时，查找本技能 memory/ 内的副本和派生摘要，移除内容，回读核查并重评依赖结论。删除优先于历史保留。日志只记删除动作和日期，避免重新写入内容。范围外备份和聊天记录不能宣称已删。

仅收集商业相关信息，不保存密码、密钥或银行卡账号。其他技能档案与全局记忆遵循各自范围和权限。
