# 自我评估与行为取证

八维度为覆盖检查，每轮选择最影响当前决策的一个缺口。

| 维度 | 调查重点 |
| --- | --- |
| 基本情况 | 教育、地区、学习工作、生活、收入来源 |
| 能力技能 | 专业、沟通销售、管理创造、学习解题、独立交付 |
| 兴趣动机 | 主动长期投入、喜欢厌恶、成就感、赚钱目的 |
| 经历成果 | 成功失败、困难、个人贡献、外部反馈、商业经历 |
| 资源优势 | 资金时间、人脉、设备、技术信息、渠道、地理行业与潜客 |
| 目标价值观 | 短中长期收入、生活方式、稳定自由成长、就业创业与风险 |
| 现实约束 | 周投入、预算、亏损、收入期限、责任、地区、异地合作、长期投入 |
| 性格行为 | 合作、沟通接受、自律、坚持、失败反应、决策习惯 |

逐次追问近期具体事件、本人行动、独立完成范围、结果和证据。探索最近一年主动投入最多的事情、无人监督也会做的事、他人主动求助与付费、困难解决、失败教训和经常被认可的能力。

E1 自评，E2 事件，E3 成果，E4 第三方或交易。证据形态与独立核实分开，不要求所有能力达到 E4。性格假设依据行为，可修正。

足够支撑初步机会筛选时整理画像请用户确认，非关键未知可保留。

每轮优先问能改变下一步判断的缺口。把事件、原因和结果拆成后续问题，避免在一句话中要求多项回答。近期案例优先，历史案例用于判断持续性。中性提问示例见 [客户发现](customer_discovery.md)。

## 方法来源

MIT 的自我评估涵盖价值观、兴趣、性格和技能，强调反思优先级及持续重评，用于访谈覆盖。[MIT Self assessment](https://capd.mit.edu/channels/self-assessments/)

McGill 用活动与成果寻找能力线索，区分技能和价值取舍，用于追问个人贡献与可迁移能力。[McGill Self-Assessment](https://www.mcgill.ca/caps/students/explore/self-assessment)

访问日期为 2026-11-17。E1～E4 是本技能约定，上述方法用于自我反思，未验证个人商业成功率。
